Kết nối & Đồng bộ Google Sheets thời gian thực

Google Apps Script Web App · GET / POST
Chế độ cục bộ · Chưa cấu hình URL Mọi thay đổi Thêm/Sửa/Xóa tự động lưu vào phiên làm việc và gửi POST khi có URL Web App.
Hướng dẫn cài đặt nhanh Google Apps Script (Code.gs) để đồng bộ 2 chiều

Tạo Google Sheet mới với tên sheet DoiTac_DMP, mở Tiện ích mở rộng → Apps Script, dán đoạn mã dưới đây rồi chọn Triển khai → Triển khai mới → Ứng dụng web (Quyền truy cập: Bất kỳ ai) và dán URL nhận được vào ô phía trên. 

const SHEET_NAME = 'DoiTac_DMP';
const HEADERS = [
  'id','stt','source','category','name','score','status','dmpGroup',
  'integrationModel','dmpAssessment','progress','description',
  'retailPrice','wholesalePrice','salesChannels','generalRating',
  'website','address','contact','pm','updatedAt'
];

function getSheet_() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sh = ss.getSheetByName(SHEET_NAME);
  if (!sh) sh = ss.insertSheet(SHEET_NAME);
  if (sh.getLastRow() === 0) sh.appendRow(HEADERS);
  return sh;
}

function doGet() {
  const sh = getSheet_();
  const values = sh.getDataRange().getValues();
  if (values.length <= 1) {
    return ContentService.createTextOutput(JSON.stringify({ ok: true, partners: [] }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  const cols = values[0];
  const rows = values.slice(1).filter(r => r[0]).map(r => {
    const obj = {};
    cols.forEach((c, i) => obj[c] = r[i]);
    return obj;
  });
  return ContentService.createTextOutput(JSON.stringify({ ok: true, partners: rows }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  const sh = getSheet_();
  const payload = JSON.parse(e.postData.contents || '{}');
  const action = payload.action || '';
  if (action === 'init' && Array.isArray(payload.partners)) {
    sh.clearContents();
    sh.appendRow(HEADERS);
    const rows = payload.partners.map(p => HEADERS.map(h => p[h] || ''));
    if (rows.length) sh.getRange(2, 1, rows.length, HEADERS.length).setValues(rows);
    return ContentService.createTextOutput(JSON.stringify({ ok: true, count: rows.length }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  const vals = sh.getDataRange().getValues();
  const rowIndex = vals.findIndex((r, idx) => idx > 0 && String(r[0]) === String(payload.id || (payload.partner && payload.partner.id)));
  if (action === 'delete' && rowIndex > 0) {
    sh.deleteRow(rowIndex + 1);
  } else if ((action === 'add' || action === 'update') && payload.partner) {
    const rowData = HEADERS.map(h => payload.partner[h] || '');
    if (rowIndex > 0) sh.getRange(rowIndex + 1, 1, 1, HEADERS.length).setValues([rowData]);
    else sh.appendRow(rowData);
  }
  return ContentService.createTextOutput(JSON.stringify({ ok: true, action: action }))
    .setMimeType(ContentService.MimeType.JSON);
}

3. Playbook tiếp cận & hành động khi đã liên hệ được đối tác

Kịch bản xử lý thực chiến cho Nhóm 4 & Nhóm 5
Kịch bản A · Luồng Xanh (Tiềm năng cao)

Chốt nhanh POC & Đưa lên DMP trong 10–15 ngày

  1. Trong 24h sau khi nhận phản hồi: Gửi One-pager giới thiệu sàn dimarket.vn (đầu số 1376, thanh toán TKC/TKTT & ví/ngân hàng) và bảng câu hỏi kỹ thuật 5 điểm (API cấp mã hay kho voucher, mệnh giá SKU, chiết khấu B2B, hạn dùng mã, cơ chế xuất hóa đơn).
  2. Cuộc họp đầu tiên (30 phút): Thống nhất AOV mục tiêu (20k–100k/giao dịch để phù hợp thanh toán viễn thông hoặc Hybrid) và lựa chọn 1 trong 3 hình thức: (a) Thuê bao ngày/tháng qua 1376 có miễn phí ngày đầu; (b) Bán lẻ e-code/license thanh toán ngoài VT; (c) Ghép Bộ KIT eSIM đồng thương hiệu.
  3. Chuyển giao kỹ thuật: Nhóm 4 lập Business Case (giá vốn, biên tối thiểu, cam kết sản lượng) → Nhóm 5 cấu hình trên DMP, cấp tài khoản test cước VasCloud, chạy UAT với VNPT-IT.
Kịch bản B · Luồng Vàng (Đã liên hệ / Cần tháo gỡ)

Xử lý điểm nghẽn thương mại, hóa đơn & hạn mức

  1. Vướng kế hoạch kênh bán (như Golden Gate): Chuẩn bị ngay khung đề xuất phân bổ kênh (MyVNPT, VNPT Money, VinaPhone Plus, Pack360) và dự kiến sản lượng theo Tờ trình 641 (nhóm E-Voucher ~50.490 giao dịch/năm đầu).
  2. Vướng chứng từ/hóa đơn voucher (như CGV): Rà soát theo Thông tư 219/2013/TT-BTC và Nghị định 123/2020/NĐ-CP; làm rõ thời điểm xuất hóa đơn GTGT và điều khoản gia hạn voucher tồn kho trước 1 tháng với Kế toán trước khi ký.
  3. Giá trị đơn hàng cao (>100k, như Ticketbox, Tripi, Prep.vn): Không ép qua TKC; áp dụng mô hình Hybrid (chu kỳ đầu thanh toán qua ví/ngân hàng, gia hạn qua TKC) hoặc luồng thanh toán ngoài VT theo đề xuất Tờ trình 641.
Kịch bản C · Luồng Đỏ (Không phù hợp DMP B2C)

Chuyển tuyến B2B/SME đúng quy chế, không bỏ phí nguồn

  1. Dấu hiệu nhận biết: Sản phẩm SaaS tính theo user/tháng cho doanh nghiệp (Base.vn), phần mềm kế toán DN lớn (MISA AMIS bản DN), dịch vụ SOC 24/7 / Pentest / FIDO2 / eContract theo dự án (VinCSS, NCS, NetSecurity/ATM, IntrustCA).
  2. Hành động chuẩn: Ghi nhận trạng thái Đỏ · Không tiềm năng DMP B2C, hoàn tất biên bản ghi nhận đầu mối và bàn giao hồ sơ sang Nhóm 3 (Kinh doanh Đối tác — Trưởng nhóm Đặng Duy Thắng).
  3. Cơ hội khai thác lại: Đề xuất Nhóm 3 ghép thành Combo SME (Internet + Hóa đơn điện tử + Chữ ký số VNPT + SaaS đối tác); tách riêng nếu đối tác có gói siêu nhỏ cho cá nhân/hộ KD (ví dụ eSign cá nhân).
